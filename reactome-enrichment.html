12  Reactome enrichment analysis

ReactomePA is designed for reactome pathway based analysis (Yu and He 2016). Reactome is an open-source, open access, manually curated and peer-reviewed pathway database.

12.1 Chapter overview

Aspect Reactome analysis
Questions Which curated Reactome pathways are over-represented or show coordinated signal in a ranked gene profile?
Input Entrez IDs from a supported organism; GSEA uses a named ranked vector.
Methods Pathway ORA and GSEA, Reactome-specific pathway visualization, and comparisons across gene clusters.
Main functions enrichPathway(), gsePathway(), viewPathway(), and compareCluster().
Output enrichResult / gseaResult objects and optional Reactome pathway diagrams.
Main limitations The supported species set is limited; ID conversion and Reactome release affect coverage. Confirm species and mapping before interpreting absent pathways.

12.2 Supported organisms

Currently ReactomePA supports several model organisms, including ‘celegans’, ‘fly’, ‘human’, ‘mouse’, ‘rat’, ‘yeast’ and ‘zebrafish’. The input gene ID should be Entrez gene ID. We recommend using clusterProfiler::bitr() to convert biological IDs.

12.3 Reactome pathway over-representation analysis

Enrichment analysis is a widely used approach to identify biological themes. ReactomePA implemented enrichPathway() that uses hypergeometric model to assess whether the number of selected genes associated with a reactome pathway is larger than expected.

12.5 Pathway Visualization

ReactomePA implemented the viewPathway() to visualize selected reactome pathways. More general purpose visualization methods for ORA and GSEA results are provided in the enrichplot package and are documented in Chapter 26. See Figure 12.1 for an example.

viewPathway("E2F mediated regulation of DNA replication", 
            readable = TRUE, 
            foldChange = geneList)
